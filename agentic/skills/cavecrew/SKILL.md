# cavecrew — Delegação de Subagentes Comprimidos

## Uso
- `cavecrew-investigator`: Para pesquisar e localizar código (retorno ~60% menor).
- `cavecrew-builder`: Para edições em 1-2 arquivos.
- `cavecrew-reviewer`: Para code review e diffs comprimidos.
