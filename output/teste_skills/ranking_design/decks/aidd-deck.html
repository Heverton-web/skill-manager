O que é AIDD?

AI-Driven Development é a evolução paradigmática do desenvolvimento de software onde agentes de IA atuam como colegas de equipe — não apenas como ferramentas de autocomplete.

🤖 Coding Agents

Claude Code, Cursor, Cline, Devin — agentes que escrevem, revisam e refatoram código autonomamente.

📐 Context Engineering

CLAUDE.md, AGENTS.md — especificações executáveis que guiam o comportamento do agente.

🔌 MCP Protocol

Model Context Protocol — ponte universal entre agentes e ferramentas externas.

Os 4 Pilares

  • Parte I — Fundamentos: Evolução do desenvolvimento, coding agents, SWE-bench, perception gap
  • Parte II — Context & SDD: Context Engineering, Spec-Driven Development, multi-IDE
  • Parte III — Protocolos: MCP, orquestração multi-agente, Fable Method
  • Parte IV — Mundo Real: Adoção corporativa, dívida técnica, AI Agent Owner, engenheiro de intenção

↑ 88%
