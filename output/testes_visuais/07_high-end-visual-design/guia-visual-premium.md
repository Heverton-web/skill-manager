# Guia de Estilo Visual Premium

## Filosofia de Design
Design premium não é sobre adicionar elementos — é sobre **remover** distrações até que apenas a essência permaneça.

## Princípios
1. **Hierarquia clara**: Um elemento por nível de atenção
2. **Tipografia como identidade**: A escolha tipográfica define o tom
3. **Espaço como elemento**: O vazio direciona o olhar
4. **Cor com propósito**: Cada cor carrega significado

## Paleta Premium
- Background escuro: #0a0a14 / #0f0f1a
- Texto principal: #e8e8f0
- Texto secundário: #8888aa
- Accent primário: #6c63ff
- Accent secundário: #00d4aa
- Destaque: #ff6b9d
- Neutro: #ffaa33

## Tipografia Premium
- Display: Newsreader (serif), pesos 300-700
- UI: Inter (sans), pesos 400-700
- Mono: JetBrains Mono para código
