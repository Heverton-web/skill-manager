# Padrões de Selos Generativos

## 5 Padrões Disponíveis

| Padrão | Aparência | Ideal para |
|--------|-----------|------------|
| crystal-lattice | Polígonos concêntricos simétricos | Capítulos técnicos, densos |
| particle-orbit | Partículas orbitais com trilhas | Aberturas de Parte, introduções |
| flow-field | Campos de fluxo Perlin orgânicos | Temas exploratórios, narrativos |
| wave-interference | Ondas circulares concêntricas | Transições, mudanças de contexto |
| noise-strata | Estratos horizontais de ruído | Conclusões, resumos, fechamentos |

## Seeds Determinísticas
