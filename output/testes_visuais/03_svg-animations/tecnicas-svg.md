# Técnicas de Animação SVG

## 3 Técnicas Demonstradas

### 1. Stroke Drawing
Anima o traço de caminhos SVG usando stroke-dasharray + stroke-dashoffset. Ideal para diagramas de fluxo e conectores.

### 2. Shape Morphing
Anima a transição entre formas geométricas usando CSS keyframes na propriedade `d`. Cria ilusão de transformação contínua.

### 3. Motion Path
Anima objetos ao longo de trajetórias definidas. Combina transform CSS com keyframes para movimento bidimensional.

## Acessibilidade
`@media (prefers-reduced-motion: reduce)` desativa todas as animações automaticamente.
