Skill Manager Documentação

Gerenciador universal de Agent Skills para todas as IDEs agênticas do mercado.

O Skill Manager é uma ferramenta de terminal + servidor HTTP que permite instalar, remover, ativar e desativar Agent Skills em 13 IDEs diferentes com um único comando. Ele combina uma TUI interativa (5 passos guiados), um dashboard visual com scoring inteligente, e um servidor REST que executa operações reais via npx skills add/remove.

✨ Destaques: Zero dependências externas · 482 skills catalogadas · 14 categorias · Scoring 0-100 · Instalação batch com fallback triplo · API REST documentada · Dashboard com toggle em tempo real

📦 Instalação

Pré-requisito único: Node.js 18+. Nenhuma dependência externa necessária.

✅ Pré-requisito único: Node.js 18+. Nenhuma dependência externa — apenas módulos nativos do Node.js.

O Skill Manager é um conjunto de scripts locais (ES Modules .mjs). Não é um pacote npm publicado — você copia os scripts para seu projeto e executa diretamente.

1. Copiar os scripts para o projeto

cp -r ../skill-manager/scripts ./scripts

2. Executar diretamente

node scripts/skill-manager.mjs --help

3. Criar alias (recomendado)

# Bash / Zsh
alias sm="node scripts/skill-manager.mjs"
alias sm-serve="node scripts/skill-manager.mjs --serve"

# PowerShell (no perfil $PROFILE)
function sm { node scripts/skill-manager.mjs @args }
Set-Alias sm-serve "node scripts/skill-manager.mjs --serve"

🚀 Cenário 1: Projeto Novo

🎯 Situação: Você está começando um projeto do zero e quer configurar todas as skills necessárias de uma vez, sem instalar uma por uma manualmente.

Passo a Passo

# 1. Crie o projeto
mkdir meu-novo-projeto && cd meu-novo-projeto

# 2. Copie o Skill Manager para o projeto
# (a partir da instalação local do Skill Manager)
cp -r ../skill-manager/scripts ./scripts

# 3. Execute a TUI interativa
node scripts/skill-manager.mjs

O que acontece na TUI

  1. Selecionar IDEs — Marque Claude Code, Cursor, ou outras que você usa
  2. Escolher Skills — Navegue por 14 categorias, veja o score de cada skill, selecione as desejadas (skills com score ≥50 vêm pré-marcadas)
  3. Definir Escopo — local (só neste projeto), global (todas IDEs/todos projetos), ou ambos
  4. Dashboard Visual — Opte por instalar o painel HTML para gestão contínua
  5. Confirmar — Veja o resumo completo e clique SUBMIT
💡 Dica: Para projetos novos, comece com as categorias Desenvolvimento & Engenharia + Token Economy + Design & Visual. Instale em escopo local para manter o projeto portátil.

🌐 API REST

O servidor HTTP expõe 5 endpoints REST. Todas as respostas são JSON (exceto o dashboard HTML).

GET /

Dashboard HTML completo — template processado com skills reais

GET /api/config

Configuração completa: todas skills, estado ativo/inativo, categorias, metadados

{ "allSkills": [...], "activeSkills": [...], "categories": [...],
"activeCount": 42, "totalSkills": 482, "totalCategories": 14 }
POST /api/toggle

Ativar/Desativar skill individual. Executa npx skills add/remove real.

// Request
{ "skill": "lean-ctx", "active": true }

// Response
{ "success": true, "skill": "lean-ctx", "active": true, "activeCount": 43 }
POST /api/save

Salvar lista completa em lote. Inicia job assíncrono, retorna jobId para polling.

// Request
{ "activeSkills": ["lean-ctx", "caveman", "headroom", "..."] }

// Response
{ "success": true, "jobId": 1 }
GET /api/job/:id

Poll do resultado do job batch. Use para acompanhar progresso da instalação.

{ "completed": true, "success": true, "installed": 15, "removed": 3,
"errors": [], "activeCount": 42, "message": "✅ 15 instaladas..." }
🔌 CORS: Todos os endpoints incluem cabeçalhos Access-Control-Allow-Origin: * para integração com qualquer frontend ou ferramenta.

📊 Sistema de Scoring

Cada skill é avaliada em 3 testes objetivos, gerando um score consolidado de 0 a 100.

T1 — Qualidade (0-40)

Frontmatter (name, description, license) +15
Descrição longa +10
Seções ≥3 +5, ≥6 +5
Exemplos de uso +5

T2 — Capacidade (0-35)

Frameworks +10
Formatos de saída +10
Scripts/Assets +8
Edge cases +7

T3 — Complexidade (0-25)

Tamanho (>80 linhas) +8
Workflow documentado +6
Metadados (version, author) +6
Validação +5

Classificação por Score

≥ 70🔵 ExcelenteVerdePré-selecionada automaticamente
40 — 69🟡 BoaAmareloDisponível para seleção manual
< 40🔴 BásicaVermelhoNão pré-selecionada

Skills com score ≥ 70 são automaticamente pré-selecionadas na TUI para facilitar a instalação.

⚡ Instalação Batch

O sistema de instalação em lote usa um algoritmo de fallback triplo para garantir que o máximo de skills seja instalado, mesmo em cenários adversos.

Algoritmo de Fallback

function installBatch(skills) {
  // Tentativa 1: Batch completo
  try {
    npx skills add "skill1" "skill2" ... "skillN" -y
    return OK
  } catch {
    // Tentativa 2: Sub-lotes de 5
    for (batch of chunks(skills, 5)) {
      try {
        npx skills add "s1" "s2" ... "s5" -y
      } catch {
        // Tentativa 3: Individual
        npx skills add "skill" -y
      }
    }
  }
}
🛡️ Proteções extras:
  • batchRunning guard — Impede dupla execução simultânea (evita lock do npm)
  • try/finally — Garante reset da flag mesmo em caso de exceção
  • Timeout configurável: 180s para batch, 120s para individual, 30s para remove
  • Relatório de erros: Skills com falha são reportadas individualmente sem abortar o lote

💪 O Poder da Aplicação

O Skill Manager não é apenas mais um instalador de skills. É uma plataforma de gestão de ecossistema para o crescente mundo das IDEs agênticas. Aqui está o que o torna único:

🎯 1. Universalidade

Não importa qual IDE você usa — Claude Code, Cursor, Windsurf, Codex, Freebuff, Grok, ou qualquer outra. O Skill Manager funciona para todas. Uma ferramenta para todo o ecossistema.

⚡ 2. Zero Fricção

Zero dependências externas. Um único comando. 5 passos na TUI. Ou um servidor HTTP com dashboard visual. De 0 a 482 skills configuradas em segundos.

🔬 3. Inteligência de Scoring

Nem toda skill é igual. O scoring 0-100 avalia objetivamente a qualidade, capacidade e complexidade de cada skill. Skills ranqueadas da melhor para a pior em cada categoria.

🔄 4. Toggle Real, Não Cosmético

Diferente de ferramentas que só salvam preferências no navegador, o dashboard do Skill Manager executa npx skills add/remove de verdade. Cada clique = operação real no sistema.

📊 5. Visibilidade Total

Dashboard com 14 categorias, busca em tempo real, indicadores de ativação, barra de progresso. Você vê exatamente o que está instalado, onde e com que qualidade.

🔌 6. API Aberta

5 endpoints REST documentados. Pode ser consumido por scripts, CI/CD, outras ferramentas. Integrável com qualquer stack.

🛡️ 7. Robusto por Design

Fallback triplo de instalação, guard contra dupla execução, try/finally em operações críticas. Construído para não quebrar.

🌍 8. Ecossistema Vivo

482 skills catalogadas de 5+ repositórios diferentes. Testes de estresse aplicados. Rankings por categoria. Um mapa vivo do ecossistema de Agent Skills.

🏗️ Filosofia: O Skill Manager foi construído com a crença de que o ecossistema de Agent Skills é tão importante quanto o de pacotes npm. Assim como o npm revolucionou o JavaScript, uma boa gestão de skills pode revolucionar o desenvolvimento com IA agêntica.

❓ FAQ

Preciso instalar algo além do Node.js?

Não. O Skill Manager usa apenas módulos nativos do Node.js. Zero dependências npm extras.

O dashboard realmente instala/remove skills?

Sim! Diferente de dashboards cosméticos, o servidor HTTP executa npx skills add e npx skills remove de verdade a cada toggle.

Funciona no Windows?

Sim. Todo o código foi testado no Windows. O servidor HTTP usa caminhos normalizados com path.resolve e fileURLToPath para compatibilidade cross-platform.

Quantas skills posso gerenciar?

O sistema foi testado com 482 skills de 6 repositórios diferentes, sem degradação de performance.

Como faço backup da configuração?

A configuração é salva automaticamente em .skill-manager-config.json na raiz do projeto. Basta copiar este arquivo.

Posso usar com IDEs não listadas?

Sim! Use o perfil Custom/Genérico que instala skills no diretório .agents/skills/, formato universal compatível com a maioria das ferramentas agênticas.

O servidor HTTP é seguro?

O servidor escuta apenas em 127.0.0.1 (localhost), inacessível de outras máquinas. Ideal para desenvolvimento local.

Como atualizar as skills instaladas?

Use a TUI com a opção "Reinstalar" ou o dashboard visual para ativar/desativar individualmente. O sistema sempre baixa a versão mais recente via npx skills add.
