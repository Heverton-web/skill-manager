Visão Geral

O que é o Skill Manager?

Um gerenciador universal de Agent Skills para todas as IDEs agênticas do mercado. Instale, ative e desative skills com um clique — via terminal ou dashboard visual.

🖥️

TUI Interativa

Interface de terminal com 5 passos: selecione IDEs, escolha skills por categoria, defina escopo, confirme e instale em lote.

📊

Dashboard Visual

Painel HTML com categorias, scoring 0-100, toggle switches, busca e barra de progresso. Ative/desative em tempo real.

🌐

Servidor HTTP

Mini servidor REST que executa npx skills add/remove de verdade via API. Toggles com efeito real, não cosmético.

⚡

Instalação Batch

Instala múltiplas skills em lote com fallback triplo (batch completo → sub-lotes de 5 → individual). Até 10x mais rápido.

🎯

Scoring 0-100

Cada skill recebe score baseado em 3 testes: Qualidade (T1), Capacidade (T2) e Complexidade (T3). Skills ranqueadas por categoria.

🔧

13 IDEs Suportadas

Claude Code, Cursor, Windsurf, Codex CLI, Antigravity, OpenCode, Freebuff, MimoCode, Grok, Oh My Pi, Cline, GitHub Copilot, Custom.

🔌 API REST (servidor)

GET / → Dashboard HTML
GET /api/config → JSON: skills, estado, cats
POST /api/toggle → {skill, active} → npx add/remove
POST /api/save → {activeSkills:[...]} → batch job
GET /api/job/:id → Poll resultado do batch
GET /favicon.ico → 204 (silencioso)

Cenário 1

🚀 Projeto Novo

Você está começando um projeto do zero e quer equipá-lo com as melhores skills desde o início.

🎯 Objetivo: Setup completo em 1 comando

Em vez de instalar skills uma por uma manualmente, use o Skill Manager para configurar tudo de uma vez.

📋 Passo a Passo

# 1. Clone seu projeto
git clone meu-projeto && cd meu-projeto

# 2. Rode o Skill Manager
node scripts/skill-manager.mjs

# 3. Selecione IDEs → Escolha skills
# 4. Defina escopo → SUBMIT

# 5. (Opcional) Inicie o servidor
node scripts/skill-manager.mjs --serve
→ http://localhost:3030

💡 Dicas para Projeto Novo

• Escopo Local — skills ficam só neste projeto

• Comece com as categorias essenciais: Desenvolvimento Token Economy

• Ative o dashboard visual para gerenciar depois

• Skills com score ≥ 50 são pré-selecionadas automaticamente

Qualidade

Sistema de Scoring

Cada skill é avaliada em 3 dimensões, gerando um score consolidado de 0 a 100

T1 — Qualidade (0-40)

Avalia a estrutura do SKILL.md:

• Frontmatter com name + description + license +15

• Descrição longa (>100 chars) +10

• Seções (≥3 = +5, ≥6 = +5) +10

• Exemplos de uso +5

T2 — Capacidade (0-35)

Avalia o potencial técnico:

• Frameworks suportados +10

• Formatos de saída (HTML, SVG, JSON, etc.) +10

• Scripts e assets estruturados +8

• Tratamento de edge cases +7

T3 — Complexidade (0-25)

Avalia a profundidade:

• Tamanho do documento +8

• Workflow documentado +6

• Metadados (version, author) +6

• Validação e testes +5

Score Final: T1 até 40 + T2 até 35 + T3 até 25 = 100

Diferenciais

O Poder do Skill Manager

Por que esta ferramenta muda a forma como você gerencia skills de IA agêntica

🎯 1. Zero Dependências Externas

O servidor HTTP usa apenas módulos nativos do Node.js (http, fs, path, child_process). O dashboard template é HTML + CSS puro, sem frameworks, sem bundlers, sem npm install extra.

⚡ 2. Toggle com Efeito Real

Diferente de dashboards cosméticos que só salvam estado no localStorage, nosso servidor executa npx skills add/remove de verdade. Cada toggle é uma operação real no sistema de arquivos.

🔧 3. Multi-IDE de Verdade

Suporte a 13 IDEs diferentes com configurações específicas para cada uma (diretório de skills, formato de config, comandos de instalação). Uma ferramenta para todo o ecossistema.

📊 4. Scoring Inteligente

Cada skill recebe um score 0-100 baseado em 3 testes objetivos (Qualidade, Capacidade, Complexidade). Skills pré-selecionadas (≥50) e ordenadas da melhor para a pior em cada categoria.

🛡️ 5. Instalação Robusta

Sistema de fallback triplo: tenta batch completo → sub-lotes de 5 → instalação individual. Além de guard contra dupla execução e try/finally no batch job. Sua instalação não quebra.

🌐 6. API REST Aberta

5 endpoints REST documentados. Pode ser consumido por qualquer ferramenta: scripts, CI/CD, outras IDEs, integrações. GET /api/config, POST /api/toggle, POST /api/save, GET /api/job/:id.
